# Contributing to arena_camera_ros2

Thank you for your interest in contributing. This project accepts contributions
via GitHub pull requests.

## Getting Started

1. Fork the repository and create a branch from `develop`.
2. Make your changes with clear, focused commits.
3. Ensure your changes do not break existing functionality.
4. Open a pull request against the `develop` branch.

## Code Style

- Follow [PEP 8](https://pep8.org/) for Python code.
- Keep functions small and well-documented with docstrings.
- Use type hints where practical.

## Reporting Issues

Use the GitHub issue tracker to report bugs or request features. Please include:

- ROS version and Ubuntu version
- Arena SDK version
- Camera model and serial number (can be anonymized)
- Steps to reproduce the issue
- Expected vs. actual behavior
